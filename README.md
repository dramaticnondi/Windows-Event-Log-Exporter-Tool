## What This Tool Does

- Export all Windows event logs at once (System, Application, Security, Setup)
- Save to multiple formats: CSV, EVTX, XML, TXT
- Filter by log type and date
- Export specific logs or all logs
- Backup event logs for analysis
- Works on Windows 10 and 11
